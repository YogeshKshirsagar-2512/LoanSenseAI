Dataset Limitations

Critical issues that impact model reliability, fairness, and real-world deployment.

HIGH SEVERITY
⚖️

Class Imbalance

The target variable is heavily skewed — 68.6% rejected vs 31.4% approved (ratio 1:2.2). Models trained on this data will be biased toward predicting "No" (rejection), artificially inflating accuracy while performing poorly on the minority class.

Impact

  • High accuracy ≠ good model (accuracy paradox)
  • Poor recall for approved loans
  • Model may default to always predicting "Rejected"

Mitigation

SMOTE Class Weights F1-Score Metric Stratified Split
HIGH SEVERITY
🕳️

Uniform Missing Data Pattern

Exactly 50 values (5%) are missing per every column — including the target variable. This suspiciously uniform pattern suggests the data may be synthetically generated rather than collected from real-world loan applications. Real data would have non-uniform missing patterns.

Impact

  • 50 rows have missing target labels — can't be used for training
  • Uniform missingness hints at artificial dataset
  • Imputation strategy choice significantly affects results

Mitigation

SimpleImputer (mean/mode) Drop target-null rows MICE Imputation
MEDIUM SEVERITY
📉

Small Sample Size

Only 1,000 records (950 usable after dropping target nulls) with 20 features is a relatively small dataset for building reliable ML models. This limits the model's ability to learn complex, non-linear patterns and increases the risk of overfitting.

Impact

  • High variance in cross-validation scores
  • Risk of overfitting, especially with KNN
  • After train-test split, only ~760 training samples

Mitigation

Cross-Validation Regularization Feature Selection
HIGH SEVERITY
🚻

Gender Imbalance & Potential Bias

The dataset contains 571 males (60%) vs 379 females (40%). Female applicants show a slightly higher approval rate (34.2%) than males (28.8%). Using gender as a feature risks encoding discriminatory patterns into the model.

Impact

  • Model may learn gender-based discriminatory patterns
  • Legal & ethical concerns in financial lending (ECOA, GDPR)
  • Gender as a protected attribute shouldn't drive loan decisions

Mitigation

Drop Gender Feature Fairness Auditing Adversarial Debiasing
MEDIUM SEVERITY
🎯

Weak Feature Separability

Most categorical features show nearly identical approval rates across categories: Property Area (~30% all areas), Education (32.8% vs 27.2%), Marital Status (similar). Only Credit Score (651.6 vs 726.9) and Employment Status show meaningful separation.

Impact

  • Many features add noise rather than signal
  • Models may not significantly outperform baseline
  • Overfitting on irrelevant features

Mitigation

Feature Importance Analysis PCA / Dimensionality Reduction Remove Low-Variance Features
MEDIUM SEVERITY
🧪

Likely Synthetic / Simulated Data

Multiple signals indicate the data is artificially generated: perfectly uniform 5% missing rate across ALL columns, near-perfect uniform distribution of Loan Purpose categories (178–202 each), zero duplicate rows, and suspiciously rounded statistics.

Impact

  • Patterns learned won't generalize to real applications
  • Correlations between features may not reflect reality
  • Suitable for learning ML workflows, not production deployment

Mitigation

Acknowledge Limitations Use Real Datasets for Validation Focus on Methodology
LOW SEVERITY
📅

No Temporal Information

The dataset lacks timestamps or date features. In real-world lending, economic conditions, interest rates, and lending policies change over time. Without temporal context, the model cannot account for time-based trends.

Impact

  • Cannot detect concept drift or seasonal patterns
  • No ability to model changing economic conditions
  • Static snapshot may not represent current trends

Mitigation

Document Assumption Regular Retraining
LOW SEVERITY
📦

Oversimplified Categories

Education is binary (Graduate / Not Graduate), Gender is binary, Property Area has only 3 levels. Real-world data would have more granular categories (PhD, Masters, High School, etc.) which could provide better predictive power.

Impact

  • Loss of potentially important granular information
  • Binary features limit feature interaction patterns
  • Non-binary gender identities are excluded

Mitigation

Feature Engineering Interaction Terms

Key Insights

Data-driven findings that reveal patterns in loan approval decisions.

01

Credit Score is the Strongest Predictor

Approved applicants have an average credit score of 726.9 vs 651.6 for rejected ones — a 75-point gap. The minimum credit score among approved applicants is 651, suggesting a clear threshold effect.

Score Gap +75.3 pts
02

Income Matters Less Than Expected

The mean income difference between approved (₹11,797) and rejected (₹10,406) applicants is only ₹1,391 — suggesting income alone is insufficient for prediction. The ranges overlap almost completely.

Income Gap ₹1,391
03

Contract Workers Get Most Approvals

Counter-intuitively, contract workers have the highest approval rate at 39.7%, while salaried employees are at 29.2%. This is unusual and may indicate data artifacts in the synthetic dataset.

Contract Rate 39.7%
04

Geographic Location Has Minimal Impact

Approval rates are nearly identical across areas: Urban (31.8%), Rural (30.2%), Semiurban (30.0%). Property area provides almost no predictive signal for this dataset.

Max Spread 1.8%
